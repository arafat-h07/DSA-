## 🧠 About This Repository

This repository contains my journey through **Data Structures and Algorithms (DSA)**.

It was created primarily for **DSA lab practice, implementation, experimentation, and strengthening problem-solving skills**.

Rather than simply memorizing implementations, the goal is to understand:

* How different data structures work internally
* How algorithms solve problems
* Time and space complexity
* Different approaches to the same problem
* How to write clean and efficient code
* How fundamental DSA concepts are applied in real programs

> 🚀 **Learn → Implement → Analyze → Improve**

## ⏱️ Complexity Matters

One of the main goals of this repository is not only to make an algorithm work, but also to understand **how efficiently it works**.

For each algorithm, I aim to understand:

```text
Time Complexity
      +
Space Complexity
      +
Implementation
      =
Better Problem Solving
```

For example:

| Algorithm / Structure | Average Time | Worst Case |
| --------------------- | -----------: | ---------: |
| Linear Search         |         O(n) |       O(n) |
| Binary Search         |     O(log n) |   O(log n) |
| Bubble Sort           |        O(n²) |      O(n²) |
| Stack Push            |         O(1) |       O(1) |
| Stack Pop             |         O(1) |       O(1) |
| Queue Enqueue         |         O(1) |       O(1) |
| BST Search            |     O(log n) |       O(n) |

> Complexity can vary depending on the implementation and input conditions.
